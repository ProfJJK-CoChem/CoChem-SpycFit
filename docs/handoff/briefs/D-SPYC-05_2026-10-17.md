### Options
**A. Sheet A: ipywidgets + Plotly under Voila as a BASE tab and notebook; API, CLI; other stacks deleted.**
- Pros: existing code; one path.
- Cons: drag only via Plotly shapes; "BASE tab" still needs H1-H3.
- Risks: drag becomes custom JavaScript late.

**B. Sheet B: library, API and CLI only in the first release.**
- Pros: fastest tested core.
- Cons: conflicts with "are required" unless read as order.
- Risks: API shaped without a UI consumer; drag semantics (SF-HITL-002c) found late.

**C. (new) Jupyter-widgets browser UI over the headless API; hosting fixed now; plot widget named by the PI after measured comparison.**
- H1: SpycFit's own Voila server, linked from BASE; a second forwarded port.
- H2: BASE's Voila renders a SpycFit notebook in a SpycFit-environment kernel; one port; needs a notebook path and kernelspec; cross-environment widget front ends UNVERIFIED.
- H3: BASE writes a SpycFit tab over a SpycFit adapter, like TORQ's; requests may be too slow for drag (UNVERIFIED); UI code in BASE.
- Comparison: Plotly shapes, bqplot, Bokeh, Matplotlib+ipympl, anywidget; all journeys, keyboard included; offline rendering (anywidget may load libraries "using URLs", https://anywidget.dev/en/getting-started/); redraw time on a full spectrum (no SRS target); accessible table.
- Pros: evidence-based library choice; hosting fixed for the SRS.
- Cons: BASE changes the PI must request (AGENTS.md): SpycFit in `COCHEM_MODULES`, an adapter, a new pin (devcontainer l.14; `scripts/module-distribution.json` l.149-156); H1/H2 need SF-IF-002 (work "only through ... manifests") to admit interactive and direct input, or input via BASE ingestion.
- Risks: drag unknown at G1 (no code PR before `srs-v2.0`, plan l.15); API shaped before WP-UI, package 10 (plan l.45).

**D. (new) Desktop Qt (PySide6) beside the headless API.**
- Pros: pyqtgraph movable lines (https://pyqtgraph.readthedocs.io/en/latest/api_reference/graphicsItems/infiniteline.html); BASE requires PySide6 and pyqtgraph (`CoChem-BASE/pyproject.toml` l.15, l.30); offline; X11 on HPC.
- Cons: outside BASE's browser GUI; Codespaces runs Qt offscreen (devcontainer l.9), needing a VNC desktop (https://github.com/devcontainers/features/tree/main/src/desktop-lite).
- Risks: a browser UI later anyway.
